# RESTRUCT — Проверка на читы (GTA5RP)

Прозрачное десктоп-приложение для проверки игрока во время очной модерации
(созвон/скриншер с администратором). Никуда ничего не отправляет и не работает
в фоне — весь результат виден только на экране того, кто его запустил.

## Что делает

Семь вкладок:

1. **Проверка** — сканирует список запущенных процессов (сравнение с
   `flagged_process_names`), находит процесс игры (`game_process_names`) и
   выводит список DLL, загруженных в него — модули из подозрительных папок
   (Temp, Downloads, Desktop, AppData\Roaming) помечаются отдельно.
2. **Все процессы** — полный список вообще всех процессов на компьютере с
   поиском. Клик по строке открывает панель деталей конкретного процесса
   (PID, родительский процесс, время запуска, путь) и кнопку **«Проверить
   цифровую подпись»** — реальная проверка Authenticode через `WinVerifyTrust`
   (та же, что в свойствах файла в Windows). У части системных файлов подписи
   каталожные, а не встроенные — это отражено в подсказке, не всегда «unsigned»
   значит подозрительно.
3. **Скан диска** — полный обход всех локальных дисков файл за файлом,
   включая `System32` и остальные системные папки: сверяет имя каждого файла
   со списками `flagged_file_names`/`flagged_file_keywords`. Живой счётчик
   просканированных файлов, совпадения — сразу в списке, кнопка «Остановить».
   Читаются только имена и пути — содержимое файлов не открывается.
4. **Корзина** — недавно удалённые файлы со всех дисков (разбор служебных
   `$I`-файлов Windows напрямую). Ловит частый приём — стереть чит за минуту
   до созвона: элементы младше часа подсвечиваются отдельно.
5. **Активность** — свой аналог LastActivityView/Shellbag Analyzer без
   сторонних .exe: список недавно запускавшихся программ по данным Windows
   Prefetch (видно, даже если программу уже удалили) и недавние пути/команды
   из MRU-ключей реестра (Win+R, адресная строка проводника). Полноценный
   разбор shellbag (восстановление имён удалённых папок) в это не входит —
   это отдельный сложный формат, здесь — облегчённый, но рабочий аналог.
   Также показывает, установлен ли на компьютере voidtools Everything — сам
   его не подключает (закрытый проприетарный индекс), но наш «Скан диска» и
   так проверяет каждый файл на диске без исключений.
6. **Логи** — каждая проверка (Проверка / Скан диска / Корзина / Активность)
   автоматически сохраняется файлом в папку `logs/` рядом с exe — можно
   открыть и пересмотреть после закрытия окна. Никуда не отправляется.
7. **О программе** — короткое пояснение для игрока, без лишних деталей.

Отчёт с любой вкладки можно скопировать в буфер обмена — дальше решает
администратор, ничего не решается автоматически.

## Важно понимать

Ни один локальный сканер — включая этот — не даёт 100% обнаружения. Чит,
который переименовал процесс, спрятал модуль или использует руткит-техники,
такую проверку обойдёт. Это подспорье для очной проверки администратором,
а не замена его решения.

**Это не полноценный античит.** Умелый чит легко переименует процесс или
спрячет модуль — инструмент ловит только базовый/ленивый случай и служит
подспорьем при очной проверке, а не заменой её.

## Настройка списков

Файл `flagged_processes.json` лежит рядом с `.exe` и открывается любым
текстовым редактором — списки процессов/игр/подозрительных папок можно менять
без пересборки программы. Автор скрипта не поддерживает актуальную базу
конкретных чит-менюшек под GTA5RP — этот список стоит вести самим модераторам
по факту реальных случаев.

## Архитектура

Интерфейс — HTML/CSS/JS (`web/`), рендерится нативным окном через **pywebview**
поверх движка Edge/WebView2 (уже стоит в Windows 10/11) — отсюда нормальные
CSS-анимации и вёрстка, а не то, что можно выжать из Tkinter. Вся логика
проверки — в `backend.py` (без единой строчки UI), `app.py` — тонкий мост
JS ↔ Python. Никаких сетевых запросов ни на одном уровне: webview грузит
только локальные файлы из `web/`.

## Сборка .exe из исходников

```bash
pip install -r requirements.txt
python -m PyInstaller --onefile --noconsole --name "RESTRUCT_AntiCheatCheck" --icon "icon.ico" --add-data "icon.ico;." --add-data "web;web" app.py
```

Готовый файл появится в `dist/RESTRUCT_AntiCheatCheck.exe`. Положите рядом с
ним `flagged_processes.json` — без него используются встроенные значения
по умолчанию.

## Как использовать при проверке

1. Администратор открывает созвон/скриншер с игроком, за которым закреплено
   подозрение.
2. Игроку выдаётся `RESTRUCT_AntiCheatCheck.exe` (+`flagged_processes.json`
   рядом) — например, прямо в тикете.
3. Игрок запускает файл **у себя на экране, который видит администратор**, и
   нажимает «Начать проверку».
4. Администратор своими глазами смотрит на список результатов и решает, что
   делать дальше. При необходимости — просит скопировать отчёт и прислать
   текстом в тикет.

Программа не должна запускаться скрытно или без ведома игрока — как
инструмент, так и производимая им проверка предполагают, что человек видит,
что происходит.
