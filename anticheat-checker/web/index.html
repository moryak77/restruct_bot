О программе

Restruct - Checker
Семья RESTRUCT

Локальная проверка на читы — запускается по указанию администрации во время очной проверки (созвон/скриншер).

Программа ничего не отправляет в сеть, не работает в фоне и не запускается скрытно — весь результат виден только на этом экране.
